# Synthetic PDF Test Samples

These PDF files are synthetic test documents created solely for testing
CP Barcode Manager for Vigo.

They are not company documents and do not contain production customer data,
credentials, internal system paths, or confidential business information.

## Included test files

### 0080002015202610021300.pdf
Valid filename pattern used to test normal processing and customer-reference
extraction from the PDF filename.

### CUSTOMER_PAPERWORK.pdf
Intentionally invalid filename used to test invalid filename handling and
the Needs Attention workflow.

### TEST_UPLOAD.pdf
Additional intentionally invalid filename used as a negative test case.

## Test Data

The PDF content explicitly identifies itself as synthetic test data and contains:

- TEST CUSTOMER LTD
- TEST-001
- TEST ONLY - NOT FOR BUSINESS USE

These samples allow the application and Windows Service processing workflow
to be tested without using real company or customer documents.

No production document is required to test the application.
